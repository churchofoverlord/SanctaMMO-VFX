- `EXISTING_EXACT`: dedicated prototype matches the current form execution/context.
- `EXISTING_SHARED`: an existing prototype/base is shared and either has clearly implemented branches or can legitimately provide the same visual base; notes describe any context adaptation.

- `MISSING`: no adequate current prototype covers this form. A related base or design brief does not count as implementation.
- `NOT_APPLICABLE`: passive form has no standalone cast VFX; any conditional presentation belongs to its owning active execution.

## Legacy-name findings
